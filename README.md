# Browser Automation Platform

基于 Spring Boot + Playwright 的企业级自动化测试平台。

## Features

- Playwright 自动化测试
- Workflow Engine
- Browser Pool
- Selector Engine
- Trace Viewer
- Screenshot & Video
- Redis Task Queue
- Web 管理后台

## Tech Stack

- Spring Boot 3
- Playwright
- Vue3
- Redis
- Docker

## Roadmap

- Workflow DSL
- Browser Pool
- Recorder
- Trace Viewer
- AI Assisted Selector Analysis
- Distributed Workers
